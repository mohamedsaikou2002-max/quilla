QUILLA Android WebView companion for Windows local LM Studio. Start the model server at 127.0.0.1:1234, run the run_mobile_host.ps1 PowerShell script from the repository root, and allow TCP 5000 on Private Wi-Fi firewall only. Use ipconfig to find laptop IPv4 and enter IP:5000 plus the token printed by the script. Build Android debug APK via GitHub Actions artifact or Android Studio. Local Wi-Fi traffic is unencrypted HTTP and not suitable for public/hotel networks. Never port-forward TCP 5000. The LM Studio API remains localhost-only.
